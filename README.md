# TimeTravel Agency MVP

An immersive, modern web application for a fictional luxury time travel agency. Discover temporal destinations, interact with an AI travel concierge, and find your perfect era through a personalized recommendation quiz.

## 🚀 Tech Stack

- **Framework:** React 19 + TypeScript
- **Build Tool:** Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Typography:** Playfair Display (Serif) & Inter (Sans-serif)

## ✨ Key Features

1.  **Immersive Hero Section:** High-impact visual introduction with dark futuristic aesthetics and luxury gold accents.
2.  **Agency Presentation:** Detailed insight into the safety, curation, and luxury of TimeTravel Agency.
3.  **Interactive Destination Gallery:** 
    - **Paris 1889:** Experience the Belle Époque and the Eiffel Tower.
    - **Cretaceous Period:** A raw survival adventure 65 million years ago.
    - **Florence 1504:** Immerse yourself in the heart of the Renaissance.
4.  **Simulated AI Chatbot:** "Chronos," a local rule-based temporal concierge that answers contextual questions about destinations, safety, and pricing.
5.  **Experience Quiz:** A 4-question interactive quiz that recommends a destination based on user personality and preferences.
6.  **Secure Booking Form:** A validated form for fictional transit requests.
7.  **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.

## 🛠️ Local Development

To run the project locally, follow these steps:

1.  **Clone or download** the repository.
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm run dev
    ```
4.  Open `http://localhost:5173` in your browser.

## 📦 Deployment

This is a static web application. You can deploy it easily to:
- **Vercel / Netlify:** Connect your repository and it will auto-detect the Vite configuration.
- **GitHub Pages:** Use the `gh-pages` branch or GitHub Actions to build and deploy.
- **Build manually:** 
  ```bash
  npm run build
  ```
  The production files will be in the `dist/` directory.

## 🤖 AI Development Reflection

This project was built using **Gemini CLI**, an AI-driven interactive development environment. 
- **Efficiency:** The entire project scaffolding, component architecture, and styling were implemented through a series of autonomous steps.
- **Simulated AI:** Since a real AI backend wasn't required, a local keyword-matching engine was implemented to provide a realistic "Chronos" chatbot experience.
- **Styling:** Tailwind CSS v4 was utilized for its modern, performant, and CSS-first approach to theme management.
